# CIの分割と検証範囲

2026-10-12、変更前commit `f12bc34`、[CI #52](https://github.com/akrym1582/CobolCS/actions/runs/38190154736) の完了ログを確認しました。

| 工程 | 変更前の実測 | 分割 |
|---|---|---|
| carddemoの生成・ビルド | 22分13秒、44ケース中42件を生成・ビルド | 4ジョブ、各11ケース |
| bankの生成・ビルド | 調査時点で継続中、43ケース | 4ジョブ、11／11／11／10ケース |
| RegressionTests | 12分45秒 | 2ジョブ、TestA～TestPと残り |
| その他の統合ワークフロー | 12分37秒 | 2ジョブ、Readiness・所有権等と残り |

Regressionの既存ローカルTRXでは2群の合計実行時間が約202秒／204秒になる分割を選びました。全統合試験はbranch・generationと合わせ6ジョブ、固定コーパス評価は他3種と合わせ11ジョブです。ビルド成果物を1回だけ作成して共有し、最後に全コーパス結果を統合します。実際の変更後CI時間と短縮率はまだ未計測です。並列runnerの空きとケース別の処理量で所要時間が変わります。

VSTestの実際の`--list-tests --filter`で、268件を12／35／25／53／19／124件へ重複・欠落なく割り当てることを確認しました。クラス条件と相補条件を使い、将来追加するテストも残りの群へ入ります。公開コーパスの171ケースは元lockのindex moduloで割り当てます。生成器の探索予算、固定再生、MSTest検証、生成物ビルド、独立期待値、固定IR照合を省略しません。

関連する32 testsは全件成功、skip 0。合成3ケースを通常評価と2分割評価の両方で実際に生成・ビルドし、CLIで統合して同じ件数・順序・成功を確認しました。欠落、重複、未完了、コンパイラー相違、生成下限改変、誤配、原文hash相違を拒否し、統合後もビルド失敗・独立期待値不一致・下限未達を失敗にします。分割summary単独を全体の成功として扱いません。ビルド・整形検査も成功しました。

元lock、期待IR、以前の測定結果は変更していません。今回の割当と変更前の時間は [partition.json](../tests/ci-performance/partition.json) に保存しました。公開原文はこの記録へ含めていません。ケース別・工程別durationMsを新しいsummaryへ追加し、stderrへ進捗を出します。コーパス結果とTRXはartifactへ保存し、成功判定をキャッシュしません。

変更後commit `1184d59` の [CI #53](https://github.com/akrym1582/CobolCS/actions/runs/38192915816) は全ジョブ成功しました。carddemoの評価工程は4分割の最長で7分25秒（変更前22分13秒）でした。44ケース中42件を生成・ビルドし、最後の全分割統合検証も成功しています。この時間は各評価工程の開始から完了までで、runner待ち・取得・artifact転送・最終統合を含むCI全体の時間ではありません。

C#本体の工程別測定と精密数値の改善は [runtime-performance.md](runtime-performance.md) に別途記録しました。

探索プロセスの起動削減とJSON型情報の共有は [probe-performance.md](probe-performance.md) に別途記録しました。CIの分割と同時に改善率を掛け合わせるものではありません。
